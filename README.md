# Keyboard Mouse Interaction

Is your computer mouse **bricked**, out of battery, or simply refusing to work?

Keyboard Mouse Interaction lets you control your mouse using only your keyboard.

## Keybinds

| Keys | Action |
|------|--------|
| Arrow keys | Move the cursor by 10 pixels |
| Ctrl + Arrow keys | Move the cursor by 50 pixels |
| Ctrl + Alt + Arrow keys | Move the cursor by 100 pixels |
